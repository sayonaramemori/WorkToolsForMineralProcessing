# 标注系统

## 目标

标注系统同时服务于计算结果、药剂制度和用户备注。图形行为与业务数据分离，使新增标注类型能够复用生命周期、主题和导出逻辑。

## 组成

- `AnnotationRecord`：稳定 ID、类型、样式、所有者、手动偏移和可见性；
- `AnnotationItem`：结果卡片和自定义文字的绘制、选择与拖动；
- `ReagentAnnotationItem`：药剂内容、化学式排版及锚点偏移；
- `AnnotationContentFormatter`：把结构化数据格式化为文字；
- `AnnotationManager.cpp`：结果卡同步、锚点查找和生命周期；`AnnotationManagerContent.cpp` 管理药剂与自由文字；`AnnotationManagerDisplay.cpp` 管理显示设置与本机边框偏好；`AnnotationManagerInteraction.cpp` 管理场景事件；
- `FlowGroupClipboard`：复制自由文字及所属流程组的药剂记录，粘贴时分配新 ID 并重映射物流归属；
- `CanvasView`：在画布滚动前识别 `↑`/`↓`，通过已注入的处理器请求药剂微调。

## 位置模型

```text
scenePosition = automaticAnchor + manualOffset
```

首次创建使用类型相关的默认偏移。结果标注和自定义文字可鼠标拖动；药剂标注选中后使用 `↑`/`↓` 调整。发生人工调整后设置 `manuallyPlaced=true`。以后流程移动只更新自动锚点，重算只更新文字。

药剂标注只保存垂直偏移，横坐标始终跟随所属物流的自动锚点。同一物流上的多个药剂先按稳定 ID 自动堆叠，再叠加各自的人工垂直偏移。

## 当前结果标注

所有者是稳定 `StreamId`。可显示：

- 干质量；
- 每种项目组分的品位；
- 相对原矿的全流程产率；
- 每种组分相对原矿的全流程回收率。

结果标注遍历项目级组分定义。启用“品位”或“回收率”后，每个组分各显示一行，并使用组分名称区分。

存在一个或多个外部原矿时，全流程指标均可显示；多个外部入料时，产率和回收率以其合计值为基准。也可启用“显示产品名称”，为已经命名的物流增加标题；未命名物流不使用定位信息作为名称回退。关闭全部指标及产品名称显示后隐藏卡片。

### 实测与计算结果的边框区分

“显示设置 → 区分实测值与计算值”默认开启。当前可见的质量或任一组分品位来自推算时，结果卡加粗边框；这些指标均来自参与求解的实测数据时，使用普通边框。产率、回收率和产品名称不参与判断，数值后不添加来源文字。数据协调后的观测仍按实测来源处理；未被求解器使用的部分输入不会把推算结果变成实测来源。

“显示设置 → 计算值边框线宽…”可设置 1.2–8.0 个画布单位，默认 2.4。线宽由 `ResultBorderStyle` 限定，`AnnotationItem` 的绘制范围同时包含选中时的线宽，避免粗边框在刷新或导出时被裁切。

来源区分开关和线宽由 `AnnotationManager` 通过本机 `QSettings` 记住，不写入项目、不进入撤销历史，也不触发重新计算或未保存提示。字号、文字颜色、质量单位、指标可见性等仍属于项目共享显示设置。SVG、PNG、JPEG 使用当前边框显示效果。

## 自定义文字

在画布上右键选择“添加自定义文字”。自定义文字使用自由场景坐标，
可拖动、双击编辑，选中后按 `Delete` 删除。文字内容、位置和可见性随项目保存。
每个文字图层可独立设置字体族、字号、粗体、是否显示边框与背景及文字颜色。文字颜色默认跟随全局标注颜色；记录中保存有效颜色时覆盖全局颜色，保存无效颜色则恢复跟随模式。

选中文字后可用 `Ctrl+C` / `Ctrl+V` 复制粘贴，也可与流程单元一起复制。副本使用新 ID，保留完整文字样式，并与流程组使用相同的平移偏移。计算结果卡不会作为自由文字复制。

## 生命周期

- 产生计算结果：创建缺失标注并更新已有内容，包含部分可解时已确定的物流；
- 计算失效：隐藏结果标注；
- 几何变化：刷新锚点；
- 指标变化：重新格式化内容；
- 主题变化：重绘；
- SVG、PNG、JPEG 导出：包含当前可见标注，隐藏的标注不会写入文件。

选中结果卡后按 `Delete` 只对本轮计算临时隐藏，重新计算后恢复；自由文字和药剂标注的 `Delete` 操作会删除对应记录。

## 药剂标注

药剂标注绑定稳定物流 ID，并属于当前 `ExperimentScenario`。名称、用量、单位、备注和垂直偏移随方案保存；切换方案时由 `AnnotationManager` 按稳定 ID 增删或更新图元。

- 在物流线上右键添加；
- 双击编辑内容；
- 选中后按 `↑`/`↓` 微调 2 个画布单位，按住 `Shift` 时微调 10 个单位；
- 选中后按 `Delete` 删除；
- 不支持鼠标拖动，避免与画布、物流连接和图元移动产生手势冲突；
- `^`、`_` 和花括号用于显式上下标，普通数字保持原样以兼容药剂代号。

方向键首先由 `CanvasView` 捕获，再调用 `AnnotationManager::nudgeSelectedReagents()`。只有确实选中了药剂标注时事件才会被消费；否则保留画布默认按键行为。该入口不得在场景过滤器或图元中重复实现。

### 随流程组复制

选择流程单元后复制，会自动快照当前方案中属于这些单元产品、主入料及完整复制的汇流/回流物流的药剂，无需单独选中药剂图元。粘贴时生成新的标注 ID、把 `ownerId` 映射为副本物流 ID，并保留名称、用量、单位、备注和人工偏移。

药剂偏移相对于物流锚点，不能再次叠加组粘贴位移。同一物流上按 ID 堆叠的多个药剂必须保持相对顺序；当前实现使用新批次前缀和等宽序号，避免 ID 跨位数后顺序颠倒。记录写入粘贴时的当前方案，其他方案不受影响；未复制的外部物流或不完整汇流节点的药剂不会带入副本。

- `clipboard_interaction_test`：文字及流程组药剂的复制、位置和堆叠、方案切换、撤销重做及项目往返；
