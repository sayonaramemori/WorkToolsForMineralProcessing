# AutoFlotationSheet 用户操作手册

## 1. 新建与保存项目

程序启动后自动创建一个浮选单元。顶部“项目管理”菜单提供：

- “保存项目”：保存流程拓扑、各方案数据、标注和人工布线路径；
- “导入项目”：打开 `.afs.json` 项目；
- 退出程序时，如有未保存修改，程序会询问保存、放弃或取消退出。

建议完成一段流程编辑后及时保存。新版项目格式可以读取旧项目；旧版程序不能保证读取新版项目。

## 2. 编辑浮选流程

在“流程编辑”菜单中可以选择“添加浮选单元”“添加三产品浮选单元”或“添加二分流器”。

- 单击浮选单元或物流线：选中对象；
- 拖动浮选单元：移动相连流程；
- `Ctrl++` / `Ctrl+=`：增大选中浮选单元宽度，或增加选中连接长度；
- `Ctrl+-`：减小宽度或连接长度；
- `Ctrl+B`：断开选中的连接、汇流或回流汇合点；
- 滚轮：缩放；
- 按住鼠标中键拖动：平移画布。

### 2.1 二分流器

二分流器用于把一条物流按固定比例拆成左右两条支路，且不改变各组分品位。

1. 选择“流程编辑 → 添加二分流器”；
2. 输入左支路比例，右支路自动取 `100% - 左支路比例`；
3. 像浮选单元一样连接入料及左右产品线；
4. 双击二分流器菱形符号可以修改比例。

比例必须大于 0% 且小于 100%。当左右支路均为最终产品时，只需在右侧表格填写左支路实测质量和品位；计算器按分流比例反算右支路及总入料。二分流器不生成浮选回收率等单元性能指标。

### 2.2 三产品浮选单元

选择“流程编辑 → 添加三产品浮选单元”后，画布会创建一个带左、中、右三个产品出口的浮选单元。

- 三条产品物流的稳定标识分别以 `:left`、`:middle`、`:right` 结尾；
- 每条产品都可以独立连接到下游、参与合流或返回上游入料；
- 终端产品可分别命名并录入干质量和各组分品位；
- 计算器使用“入料 = 左产品 + 中间产品 + 右产品”进行质量及各组分平衡；
- 选中单元查看结果时，详情表会显示入料及三个产品的产率、品位和回收率。

三产品单元与普通浮选单元使用相同的连接、标注、方案和导出操作；中间产品不是临时合流线，保存并重新打开项目后仍保持为可独立编辑的产品物流。

## 3. 建立普通连接、合流和回流

从尚未连接的产品箭头开始拖动：

- 拖到浮选单元顶部入料位置：建立普通连接；
- 拖到另一条可用产品线：建立产品合流；
- 拖到已有产品合流：向该合流增加一条支路；
- 拖到同一流程上游单元的入料位置：建立回流；
- 拖到已有汇流入料：继续增加输入来源。

已占用的入料线平时隐藏，但原位置保留投放热区。拖动到热区时入料线会临时显示蓝色高亮。

## 4. 手动正交布线

所有已连接的普通产品线默认按正交折线绘制。人工调整采用 10 个画布单位的网格吸附。

### 4.1 普通产品连接

1. 单击已连接产品线；
2. 选中后水平线段中部显示方形控制柄；
3. 按住水平线段或控制柄上下拖动；
4. 松开鼠标后保存为人工路线。

也可以在线路上双击，把水平段移动到双击位置。

### 4.2 产品合流

1. 单击产品汇流线；
2. 汇流横杆中心显示方形控制柄；
3. 上下拖动横杆或控制柄，调整所有支路汇合高度。

### 4.3 回流与多输入汇流

1. 单击回流汇合线；
2. 再单击需要调整的具体支路；该支路加粗高亮，其他回流节点及同组支路暂时弱化；
3. 每条支路显示两个方形控制柄：竖直走廊上的控制柄用于左右拖动，水平走廊上的控制柄用于上下拖动；
4. 各支路可以设置不同的横向位置和汇入高度，拖动时按 10 个画布单位吸附。

自动布线会为同一个汇合点的多条回流分配错开的汇入高度，减少线路完全重叠。在线路本体上单击还可以确认当前选中的是哪一条来源；随后添加药剂标注时，标注归属该支路而不是汇合后的公共入料。

### 4.4 恢复自动布线

右键单击线路，在原有标注菜单中选择：

- “恢复自动布线”：恢复普通连接或产品合流；
- “恢复全部支路自动布线”：同时清除入料汇合各支路的横向位置和汇入高度。

选中已人工调整的线路后按 `Delete` 也可以恢复自动布线。`Ctrl+B` 才会断开物流连接，两者含义不同。

## 5. 自动跨线桥

水平物流线与其他物流线垂直交叉、且交点不是显式汇流节点时，程序自动在水平线上绘制半圆跨线桥。

- 跨线桥只表示两条线路互不连接；
- 交叉不会改变物料拓扑或计算结果；
- 真正的汇合必须通过产品合流或入料汇合操作建立；
- 移动单元或调整路线后，跨线桥自动重新计算；
- 导出的流程图包含当前跨线桥。

## 6. 产品名称、组分与实验数据

右侧表格列出总入料、终端产品、中间产品和闭路所需实测物流。

- 双击名称单元格可修改产品名称；
- 在“组分设置”中添加 Cu、Pb、Zn 等组分；
- 实测物流填写干质量和各组分品位；
- 必填但未填写的单元格使用较深背景提示；
- 指定合流支路占比时，各支路干质量占比及各组分占比必须分别合计为 100%；
- 点击“重新计算”后，程序联立求解开路或多回流闭路。

欠定表示现有数据不能唯一确定全部内部物流；矛盾表示实测值、支路占比与物料守恒无法同时成立。

## 7. 试验方案

“方案设置”菜单支持新增、复制、重命名、删除和对比方案。流程拓扑与人工布线由项目共享；实测数据、药剂制度和计算结果按方案分别保存。

## 8. 标注

右键物流线可以添加药剂标注；右键画布或物流线可以添加自定义文字。

- 药剂标注：双击编辑，选中后用 `↑` / `↓` 微调，按住 `Shift` 时步长更大；
- 自定义文字：可拖动、双击编辑字体、字号、粗体和边框；
- `Delete`：删除选中的文字或药剂标注；
- “显示设置”可以控制指标、标注样式和主题。

## 9. 导出

“导出选项”菜单提供：

- 导出流程图；
- 导出 Excel；
- 设置 Excel 行顺序。

Excel 仅输出具有计算结果的产品物流。总入料和产品行都可以在顺序设置中拖动调整。

## 10. 常见问题

### 回流拖不到已占用入料

将鼠标移到目标浮选单元顶部、原入料竖线所在位置。出现蓝色高亮后再松开。

### 拖动线路却移动了产品箭头

只有已经连接的普通产品线用于调整路线；尚未连接的产品箭头仍用于建立连接。

### 交叉线为什么没有参与汇流

跨线交叉默认互不连接。必须把产品拖到目标产品线、合流节点或入料热区，才能改变拓扑。

### 如何清除人工路线但保留连接

右键线路选择“恢复自动布线”，或者选中线路后按 `Delete`。不要使用 `Ctrl+B`。
